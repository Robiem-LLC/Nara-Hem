Setup guide

Run {{name}} for your household

About 30 minutes, once. You'll start the server, give it a secure web address, create your household, then connect everyone's phones.

  1. What you need
  2. Start the server
  3. Give it a secure address
  4. Create your household
  5. Connect email
  6. Trust your browser
  7. Invite your family
  8. Connect the phones

1What you need

  • A computer that stays on with Docker and an Intel or AMD (x86-64) processor: a Linux box, a NAS such as Unraid, TrueNAS or an Intel-based Synology, or Windows with Docker Desktop. The server image isn't built for ARM boards such as the Raspberry Pi yet. Portainer makes it point-and-click, but plain Docker Compose works too.
  • A domain on Cloudflare (the free plan is fine) for a secure HTTPS address without opening ports on your router. Any other HTTPS reverse proxy also works.
  • An email account that can send mail by SMTP, such as your email provider's SMTP server with an app password. {{name}} emails invitations and the codes that register each phone.

2Start the server

The server is two containers: {{name}} and its PostgreSQL database. Download the stack file, or copy it from below.

  1. In Portainer, open Stacks → Add stack → Web editor and paste the stack file.
  2. Under Environment variables, add:
    Name Value
    NARAHEM_IMAGE {{image}}
    NARAHEM_PUBLIC_URL The exact address you'll use in step 3, such as https://family.example.com
    NARAHEM_DB_PASSWORD A long random password. Never change it after the first start.
  3. Click Deploy the stack. Your data is kept in /opt/docker/narahem on that computer (set NARAHEM_DIR to use another folder).

The server listens on port 8186 with plain HTTP, so don't forward that port on your router. Step 3 adds HTTPS in front of it.

Using Docker Compose instead of Portainer

Save the stack file as compose.yaml in a new folder, create a .env file beside it with the three variables above (one NAME=value per line), then run docker compose up -d.

3Give it a secure address

The phone apps only connect over HTTPS. A Cloudflare Tunnel gives you that without opening any ports or revealing your home IP address.

  1. In the Cloudflare dashboard, open Zero Trust → Networks → Tunnels and create a tunnel. Cloudflare shows a command to install its connector; run it on the same computer (the Docker option works well in Portainer too).
  2. Add a public hostname to the tunnel, such as family.example.com. Set the service to HTTP and the URL to localhost:8186, or <that computer's IP>:8186 if the connector runs in Docker.
  3. Make sure the hostname exactly matches NARAHEM_PUBLIC_URL. If it doesn't, update the variable and redeploy the stack.

4Create your household

  1. Open your address in a browser. You'll see Make this server yours.
  2. Find the one-time setup token: in Portainer, open the stack's narahem container and choose Logs. Look for the line NARAHEM FIRST-RUN SETUP TOKEN.
  3. Enter the token, a household name, your email and a password of at least 15 characters. You become the household's administrator, and setup closes for good.
  4. Sign in. The browser you set up with is trusted straight away and opens the household map.

5Connect email

  1. Open Admin settings, then Email. Type your email address and pick your provider (Gmail, iCloud, Yahoo, Fastmail, Outlook and more). The server details are filled in for you.
  2. Follow the steps shown to create an app password, paste it in, and save. Other providers: open Advanced: server details and enter them yourself.
  3. Choose Send test to me, then Confirm administrator email and open the link in the email you receive.

The server stores these settings encrypted.

6If your browser asks to be trusted

Locations are encrypted for specific devices, so your browser needs its own keys before it can show the map. This happens by itself when you sign in right after setup. If you closed that tab first, the page asks instead:

  1. On Approve your first device., the page asks for a device bootstrap token.
  2. In Portainer, open the narahem container, choose Console, connect with /bin/sh and run: 
    python manage.py device-bootstrap-token
    With Docker Compose: docker compose exec narahem python manage.py device-bootstrap-token.
  3. Paste the token and choose Trust this first device. Use a browser that only you use.

7Invite your family

  1. Open Manage household and enter each person's email address to invite them.
  2. They get an email to choose a username and password. They can also finish this in the app with Set up invited account.
  3. Once their phone joins, they appear on your map.
{{video_setup_invite}}

8Connect the phones

  1. Install the app: iPhone through TestFlight, or Android.
  2. Enter your server address, your email or phone number and your password, and sign in.
  3. Request the code (Send my six-digit code on iPhone, Send verification code on Android), then enter the six-digit code from the email or text. The phone joins the household right away.
  4. Allow location Always so the phone can share while the app is closed, and allow notifications for arrival alerts and Find My Phone.
  5. Everyone in the household sees the phone's location at first, and people who join later are added automatically. To change that, open Settings, Permissions, then Who can see this phone?
{{video_setup_phones}}

That's it. Everyone who shares with you appears on your map, and trips start recording automatically.

Optional: text messages

With a Textbelt key, you can invite people by phone number, and they can sign in with it and get their codes and reset links by text. Without one, {{name}} uses email only.

  1. Buy credit at Textbelt, and ask Textbelt support to allow links from your server's address: invitations and reset links won't send until they do.
  2. Enter the key in Admin settings under Text messages, or set NARAHEM_TEXTBELT_KEY on the server, which wins over the saved key.
  3. Send yourself a test text. When you invite someone by email, you can add their phone number too, and the invitation goes to both.

Phone numbers, codes and links pass through Textbelt.

Optional: Google Maps in the web app

The web app uses OpenStreetMap unless you give the server a Google Maps key. The iPhone and Android apps already include their own maps; this only changes the web app.

  1. In the Google Cloud console, create a project and turn on billing. Google charges only above its monthly free allowance.
  2. Under APIs & Services → Library, enable Maps JavaScript API and Geocoding API, and optionally Maps Static API for map backgrounds on trip cards.
  3. Under Credentials, create an API key. Restrict it to Websites with your address, such as https://family.example.com/*, and to the APIs you enabled. Browsers can see this key, so the restrictions are what protect it.
  4. In Portainer, add NARAHEM_GOOGLE_MAPS_API_KEY with the key to the stack's environment variables and choose Update the stack.
  5. On the Household map, choose Load Google Maps.

Google receives the area of the map you're viewing, as OpenStreetMap does; your family's locations are still decrypted only in your browser.

Keeping it running

  • Updates: in Portainer, open the stack, choose Update the stack and turn on Re-pull image. Your data stays in place.
  • Backups: back up the whole /opt/docker/narahem folder. The server-data folder holds the server's encryption key, which is needed to restore.
